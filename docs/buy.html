一个码可激活 2 台：一台电脑 + 一台手机。绑定后换设备需要重新发码，每单免费换一次。

不用。¥49 买断 v0.2 大版本内的所有更新；如果以后出 v1.0 大版本，老用户会有折扣，不强制升级。

能开发票吗？

目前是个人收款，暂时开不了发票。需要发票的话请先别付款，在公众号留言说明，我这边确认后再走能开票的渠道。

支持哪些模型？

任何 OpenAI 兼容接口：DeepSeek、OpenAI、Claude、Gemini、通义、智谱、Kimi、硅基流动、OpenRouter，API Key 自己填，费用付给模型厂商。

翻译内容会被上传吗？

不会上传到译匠的服务器（没有服务器）。但原文会发给你自己配置的模型接口，这点在隐私说明里写清楚了。
