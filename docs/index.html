FEATURES

开源免费，规则可选

软件本体不设功能门槛；知识库是可选内容，不是解锁条件。

01 / RETRIEVAL

按原文选规则，而不是全塞进去

检测文体、领域、触发特征，从可选知识库里选 5 条：具体触发优先、BM25 相关度排序、同父卡限流。事实、数字、专名永远排在风格之前；不导入知识库也能翻译，只是没有随附规则。

02 / MODES

快速 / 标准 / 严格

快速只译；标准译后做片段审校；严格再多一轮定点修复。三种路径对应三种成本与确定性，自由切换。

03 / TERMS

术语不是查表，是约束

可选知识库术语 + 本次临时术语；也可以导入自己的术语表。Aho–Corasick 多模式匹配，命中即锁定译名。

04 / CASES

整段案例，学的是处理方式

可选知识库里带 24 个整段参考译例，覆盖文学、诗歌、政经、法律、商务、科技、旅游；也可以导入自己的案例。只取方法，不要求照抄。

05 / KNOWLEDGE

父子卡、方向、阶段、冲突组

规则有 scope、stage、direction、trigger、precedence、conflict_group。同层冲突按“具体优先”，仍冲突则显式标记，不静默裁决。

06 / PRIVACY

本地软件，没有内容服务器

历史在 SQLite，知识库与 Key 用 Windows DPAPI 加密。原文只发往你选择的模型接口；译匠没有内容服务器，也没有许可服务器。

FAQ

常见问题

需要自己准备 API Key 吗？

需要。译匠不代充、不代理。任何 OpenAI 兼容的 /chat/completions 接口都可以，DeepSeek、OpenAI、GLM、Kimi、Qwen、硅基流动等。

免费开源版和可选知识库差在哪？

功能没有差别：严格模式、精修、审校、导入导出、知识库编辑全部一致。软件本体免费，知识库只是可选内容包；不买 169/260 也能使用全部功能，也可以导入自己的规则、案例和术语。购买后得到的是额外的现成知识库 JSON，不是功能解锁。

开源吗？源码在哪里？

是。译匠是开源、免费的 Windows 本地翻译软件，源码在 GitHub；软件本体不收费，知识库是可选内容包。

买了之后能退吗？

数字产品不适用七天无理由退款。如需退款或反馈，请移步微信公众号【译匠公众号】说明问题和原因，或在购买渠道按平台流程申请。详见 反馈或退款。

为什么安装时被 SmartScreen 拦？

测试版没有做代码签名。点“更多信息 → 仍要运行”。正式版会考虑签名。

和网页 AI 直接翻译比呢？

译匠不是在线翻译网站，而是装在本机的软件。它按你指定的规则和术语翻译，能告诉你用了哪条规则、哪里被审校改过；质量上限仍取决于你配置的模型，不承诺每句都更好。

支持 Mac / iOS 吗？

暂不支持。当前只提供 Windows 10/11 桌面版。
