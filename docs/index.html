FEATURES

它到底在做什么

不是让模型更聪明，而是让模型按你的标准工作。

01 / RETRIEVAL

按原文选规则，而不是全塞进去

检测文体、领域、触发特征，从 259 条卡里选 10 条：具体触发优先、BM25 相关度排序、同父卡限流。事实、数字、专名永远排在风格之前。

02 / MODES

快速 / 标准 / 严格

快速只译；标准译后做片段审校；严格再多一轮定点修复。三种路径对应三种成本与确定性，自由切换。

03 / TERMS

术语不是查表，是约束

114 条内置术语 + 本次临时术语。Aho–Corasick 多模式匹配，5 万条实测约 4ms/段；命中即锁定译名。

04 / CASES

整段案例，学的是处理方式

24 个整段参考译例，覆盖文学、诗歌、政经、法律、商务、科技、旅游。只取方法，不要求照抄。

05 / KNOWLEDGE

父子卡、方向、阶段、冲突组

规则有 scope、stage、direction、trigger、precedence、conflict_group。同层冲突按“具体优先”，仍冲突则显式标记，不静默裁决。

06 / PRIVACY

没有服务器，只有本机

历史在 SQLite，知识库与 Key 用 DPAPI 加密。原文只发往你选择的模型接口——这一点我们写清楚，不装作“完全离线”。

FAQ

常见问题

需要自己准备 API Key 吗？

需要。译匠不代充、不代理。任何 OpenAI 兼容的 /chat/completions 接口都可以，DeepSeek、OpenAI、GLM、Kimi、Qwen、硅基流动等。

免费版有什么限制？

快速 / 标准永久免费；首次启动后 72 小时内严格模式不限次，之后每天 3 次；可看完整知识库，可新增 3 条规则、1 个案例，术语只能临时使用。额外精修、片段审校、术语导入、知识库导出为付费能力。每天 3 次用完后只锁严格模式，第二天 0 点恢复。

买了之后能退吗？

数字产品不适用七天无理由退款。如需退款或反馈，请移步微信公众号【译匠公众号】说明问题和原因，或在购买渠道按平台流程申请。详见 反馈或退款。

为什么安装时被 SmartScreen 拦？

测试版没有做代码签名。点“更多信息 → 仍要运行”。正式版会考虑签名。

翻译质量比网页版好吗？

不一定每句都更好。译匠的差别在于：它按你指定的规则和术语翻译，能告诉你用了哪条规则、哪里被审校改过。质量的上限仍取决于你配置的模型。

支持 Mac / iOS 吗？

暂不支持。当前是 Windows 与 Android。
