最后更新：2026-11-06 · 译匠 v0.2.0

译匠是闭源软件，按「免费版 + 付费能力」发布。免费版可以长期使用；付费只解锁额外功能，不影响你已有的译文。

一、免费版可以做什么

  • 快速、标准两种模式，永久免费、次数不限；
  • 首次启动后 72 小时内可试用严格模式；
  • 查看完整内置知识库（252 条规则、24 个案例、114 条术语）；
  • 新增最多 3 条自己的规则、1 个案例；
  • 使用自己配置的模型接口与 Key。

二、付费能力

  • 严格模式长期可用；
  • 额外精修、片段审校；
  • 术语批量导入、知识库导出；
  • 知识库条目的新增/编辑不设上限。

付费通过激活码离线校验，绑定设备；一码可绑电脑 + 手机各一台（以购买时说明为准）。

三、你不可以做什么

  • 反编译、破解、绕过授权校验，或分发破解版本；
  • 把内置知识库整体导出后单独售卖；
  • 用本软件从事违法内容的生产或传播；
  • 把激活码公开分享或用于商业转售。

四、你的内容归你

你用译匠翻译的原文与译文，版权归你或原权利人，译匠不主张任何权利，也不会把它们上传到我们的服务器（我们也没有服务器）。

五、免责

译文由第三方大模型生成，可能存在错误、遗漏或不恰当表达。重要文件请务必人工复核，因直接使用机器译文造成的损失，译匠不承担责任。软件按「现状」提供，不承诺无缺陷运行。

六、第三方组件

Windows 版基于 Python、FastAPI、pywebview/WebView2；Android 版基于 Kotlin、Jetpack Compose、OkHttp、kotlinx-coroutines。各组件的许可协议见其官方仓库。内置知识库文本由译匠整理，案例来源见项目内《官方案例来源说明》。

七、协议变更

后续版本可能调整免费与付费的边界，但已购买的能力不会回收。重大变更会在发布页与公众号说明。
