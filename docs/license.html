许可协议

最后更新：2026-11-18 · 译匠 v0.2

译匠本体是开源、免费的 Windows 本地翻译软件，代码采用 MIT 许可。169 / 260 知识库是独立的可选 JSON 文件，购买后导入使用；不买也能使用全部功能，也可以导入自己的规则、案例和术语。

一、免费开源版可以做什么

  • 快速、标准、严格三种模式全部可用，不限次数；
  • 随包只带 1 条身份卡 KB1-M00，案例与术语为空；
  • 规则、案例、术语可自由新建、导入、修改、删除；
  • 精修、审校、知识库导出全部可用；
  • 使用自己配置的模型接口与 API Key。

二、169 / 260 知识库

  • 169 知识库：169 条规则、24 个案例、100 条精选术语；
  • 260 知识库：260 条规则、24 个案例、190 条术语；
  • 导入后可在软件内查看、修改、删除本档规则；
  • 知识库买断，无年费、无到期限制；已导入内容可长期使用。
  • 169 知识库 ¥9.9（买断）；260 知识库 ¥19.9（买断）。

三、没有激活码

当前版本不需要激活码、订单号或联网激活，也没有许可服务器。知识库通过 JSON 文件导入；请只从译匠官方渠道获取知识库文件。

四、反馈与退款

数字产品不适用七天无理由退款。若需退款或反馈，请移步微信公众号【译匠公众号】说明问题与原因，或在购买渠道按平台流程申请。详见 反馈或退款。

五、你不可以做什么

  • 删除代码中的版权声明后，把软件代码当作自己的原创作品发布；
  • 把购买的知识库文件整体转卖、公开分享或用于商业转售；
  • 用本软件从事违法内容的生产或传播。

六、你的内容归你

你用译匠翻译的原文与译文，版权归你或原权利人，译匠不主张任何权利，也不会把它们上传到译匠服务器。译匠没有内容服务器，也没有许可服务器；只有你点击翻译时，原文才会发送给你自己配置的模型服务商。

七、免责

译文由第三方大模型生成，可能存在错误、遗漏或不恰当表达。重要文件请务必人工复核，因直接使用机器译文造成的损失，译匠不承担责任。软件按「现状」提供，不承诺无缺陷运行。

八、第三方组件

Windows 版基于 Python、FastAPI、PyWebView / WebView2；各组件的许可协议见其官方仓库。内置知识库文本由译匠整理，案例来源见项目内《官方案例来源说明》。

九、协议变更

后续版本可能调整知识库内容与价格，但已购买并导入的知识库不会被回收；买断后无年费、无到期限制。重大变更会在发布页与公众号说明。
