许可协议

最后更新：2026-11-10 · 译匠 v0.2

译匠是闭源软件，按「免费版 / 轻量版 / 买断版」三档发布。免费版可以长期使用；付费只解锁额度与额外功能，不影响你已有的译文。

一、免费版可以做什么

  • 快速、标准两种模式，永久免费、次数不限；
  • 首次启动后 72 小时内严格模式不限次，之后每天 3 次；
  • 查看完整内置知识库（259 条规则、24 个案例、114 条术语）；
  • 新增最多 3 条自己的规则、1 个案例；
  • 使用自己配置的模型接口与 Key。

二、轻量版（¥49）

  • 每天 50 次严格模式；
  • 可新增/修改 50 条规则、10 个案例、20 条术语；
  • 额外精修、片段审校、术语导入、知识库导出；
  • 买断制，不按年续费。

三、买断版（¥89）

  • 全功能不限量：严格模式不限次，知识库条目不设上限；
  • 解压即用，不需要激活码，不绑定设备；
  • 大版本更新凭付款凭证在公众号领取。

免费版输入有效激活码（年费/轻量码）后升级为轻量版权益；买断版不需要激活码。

四、退款

未发货或未激活的订单 7 天内可全额退款；已激活的虚拟商品不支持无理由退款；发错版本或重复付款，核实后补发或原路退回。详见发布页 退款与售后。

  • 反编译、破解、绕过授权校验，或分发破解版本；
