隐私说明

最后更新：2026-11-11 · 适用于 Windows 与 Android 版

简单说：你的翻译内容不经过译匠服务器，我们也不做统计；翻译时原文会发送给你自己配置的模型服务商。我们不承诺完全匿名，但不会收集你的原文、译文、知识库、API Key、姓名、邮箱或手机号。

一、我们收集什么

不收集内容。译匠没有账号系统、没有内容数据库、没有埋点 SDK、没有崩溃上报。我们不要求你注册，也不知道你翻译了什么。

轻量版 / 完整版需要激活码；激活码在本机校验，不上传。若以后启用在线换机登记，只会传输订单号与随机安装 ID，不传输内容与硬件序列号，并会在本页提前说明。

二、数据存在哪里

  • Windows：设置、历史、知识库存在本机用户目录下的 SQLite 数据库；API Key 与知识库文件用 Windows DPAPI 加密，只有当前 Windows 账户能解开。
  • Android：设置与翻译记忆存在应用私有目录（SharedPreferences / SQLite）；API Key 只存本机，不随备份上传。
  • 卸载应用时，这些数据一并删除；Windows 版卸载程序会提示是否保留知识库。

三、什么会被发送出去

只有当你点击「翻译」时，以下内容会被发送到你在设置里填写的接口地址（DeepSeek、OpenAI、Claude、Gemini、通义、智谱、Kimi、硅基流动、OpenRouter 或你自己的兼容网关）：

  • 你要翻译的原文（可能包含系统提示词、命中的规则卡、术语与案例）；
  • 你配置的 API Key（作为请求头发送，仅用于鉴权）。

这些数据由该服务商的隐私政策约束，译匠无法控制。如果你处理的是保密材料，请自行评估或改用本地模型网关。

四、不会发送的内容

  • 你的翻译历史与知识库改动（除非它们作为规则/术语被拼进提示词）；
  • 除激活/换机必需的订单号与随机安装 ID 外的任何设备标识、统计信息、使用行为；
  • 激活码默认在本机离线校验；如启用在线换机，仅传输订单号与随机安装 ID。

五、第三方

译匠本身不集成广告、统计或社交 SDK。Windows 版使用系统自带的 WebView2 渲染界面；Android 版使用系统 WebView 之外的组件均为开源库（OkHttp、Kotlin Coroutines、Jetpack Compose）。

六、儿童

译匠不面向 14 岁以下儿童单独提供服务，也不会主动收集任何年龄信息。

七、你的权利

因为数据都在你本机，删除即彻底删除：Windows 卸载应用并删除数据目录；Android 在系统设置里清除应用数据或卸载。我们这边没有副本可删。

八、联系我们

隐私相关问题：微信搜索【译匠公众号】留言，或在 GitHub 仓库提 Issue。我们会在看到后回复。
